# Submission Guide

Checklist before final submission:

- [ ] Update README.md with project overview, setup steps, and screenshots
- [ ] Add demo video / presentation to `submission/`
- [ ] Add architecture / design docs to `docs/`
- [ ] Verify `.env.example` lists all required environment variables
- [ ] Confirm `package.json` scripts (`dev`, `build`, `preview`) all run cleanly
- [ ] Double-check LICENSE and author details
