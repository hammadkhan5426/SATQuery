# SIH UI

A React + TypeScript (Vite) front-end for the SIH project.

## Project Structure

```
.
├── assets/screenshots/   # UI/demo screenshots for this README
├── docs/                 # Additional documentation
├── public/               # Static assets served by Vite
├── src/                  # Application source code
│   ├── components/       # React components
│   ├── data/             # Mock/sample data
│   ├── App.tsx
│   ├── main.tsx
│   └── types.ts
├── submission/           # SIH submission materials (demo video, PPT, etc.)
├── .env.example
├── package.json
├── server.ts
├── tsconfig.json
└── vite.config.ts
```

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```
